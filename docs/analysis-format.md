# 音源解析の出力仕様 v0

`ksmauto analyze song.ogg -o analysis.json [--text analysis.txt]`

LLM が「どこに何を置くか」を判断するための材料を出す。JSON は機械用（compile/lint/render が使う）、テキストは LLM が直接読む用。

## JSON

```jsonc
{
  "version": 0,
  "audio": {"path": "song.ogg", "duration_sec": 134.2, "sample_rate": 44100},
  "tempo": {
    "bpm": 191.0,                  // 主テンポ（整数・0.5 刻みに近ければ丸める）
    "confidence": 0.92,            // 0-1
    "candidates": [[191.0, 0.92], [95.5, 0.40]],
    "changes": [],                 // テンポ変化 [{"measure": 40, "bpm": 200.0}]（検出時のみ）
    "time_sig": [4, 4]
  },
  "offset_ms": 132,                // 推奨 audio.bgm.offset（pulse 0 = 小節 0 の頭が音源の何 ms 目か）
  "measures": [                    // 小節ごとの情報。index = KSON の measure index
    {
      "index": 0,
      "start_sec": 0.132,
      "energy": 0.12,              // 小節の RMS（曲全体の最大で 0-1 正規化）
      "onsets": {                  // 各帯域の発音位置。値は小節内の拍位置（グリッドに量子化済み）と強さ
        "low":  [[0, 0.9], [2, 0.8]],      // キック・ベース帯
        "mid":  [[1, 0.7], [3, 0.7]],      // スネア・ボーカル帯
        "high": [[0.5, 0.4], [1.5, 0.4]],  // ハイハット帯
        "all":  [[0, 1.0], [1, 0.8]]
      },
      "stems": {                   // --stems を付けたときだけ（ksmauto separate の出力ディレクトリ）
        "onsets": {"kick": [[0, 1.0]], "snare": [[1, 0.9]], "hat": [[0.5, 0.7]],
                   "bass": [[0, 0.8]], "vocal": [[0.5, 0.9]], "other": [[0, 0.6]]},
        "sustain": {"bass": [[0, 1.5]], "vocal": [[0.5, 3]], "other": []},  // 鳴り続ける区間 [開始拍, 長さ拍]（1/4 拍単位）
        "vocal_pitch": [[0.5, 64.2], [0.75, 64.0]],  // 1/4 拍ごとのボーカルの音程（MIDI ノート番号、有声のときだけ）
        "other_pitch": [[0, 60], [0.5, 64]],         // other の発音ごとの、そこで鳴り始めた一番高い音（MIDI ノート番号）
        "piano_pitch": [[0, 72]]                     // piano.wav があるときだけ（onsets.piano も増える）。発音ごとの最高音
      }
    }
  ],
  "sections": [                    // 構造区間（似た小節のまとまり）
    {"start": 0, "end": 8, "label": "A", "energy": 0.3},
    {"start": 8, "end": 16, "label": "B", "energy": 0.7}
  ]
}
```

- グリッド量子化: 各オンセットは 1/4 拍（16分）と 1/3 拍（3連）のうち近い方へスナップし、ずれが大きいものは除外する。
- `sections.label` は同じ文字なら似た区間（繰り返し）。`copy` 指示の根拠になる。
- テンポ・offset・セクションは `--stems` があっても元の音源から求める。
- `stems.onsets`: ドラムはステムを NMF（キック・スネア・ハイハットの型）で分け、同時に別の打楽器がはるかに強く立ち上がった発音は漏れとして捨てる。制約: キックと同じ瞬間に鳴る、キックよりずっと弱いスネアは漏れと一緒に捨てられる（キックで拍は取れているので譜面への影響は小さい）。逆に、キックのアタックの高域が長く残る曲では、キックの位置ごとにスネアが出ることがある（毎拍キック＋クラップの重ねと区別できない。High School Love で確認。減衰の長さで判定する案も試したが、実曲では差が出なかった）。ベース・ボーカルは各ステムのスペクトルフラックスから取る。その他は半音ごとの立ち上がり（CQT の各音が自分の少し前より強くなった量の和）から取るので、伸ばしているパッドの下で弾かれるピアノの音も拾える。どれもそのステムが鳴っていない区間の発音は捨てる。鳴っているとみなすのは、RMS がステム自身の 95 パーセンタイルから 20 dB 以内、かつ最も大きいステムの 95 パーセンタイルから 40 dB 以内のとき（どちらかを下回れば鳴っていない）。
- `stems.sustain`: 1/4 拍の区間の半分以上でステムが鳴っていれば鳴っているとする。ボーカルは pYIN の有声判定も満たす区間だけ。
- `stems.other_pitch`: `other` の各発音から約 70 ms の、半音ごとの立ち上がり（C2 から 6 オクターブ）に倍音（2〜4 倍）を足し込み、上位の山のうち一番高い音を取る。伸ばしている音や和音の低音より、その瞬間に弾かれたメロディ（和音の最高音）を取りやすい。採譜ではないので、和音に埋もれた弱い発音（強さ 0.3 未満、テキストでは `.`）の音程は当てにならない。ピアノ・シンセの上下の動きを見る用。
- `stems.onsets.piano` / `stems.piano_pitch`: `separate --model htdemucs_6s` で `piano.wav` があるときだけ。`piano.notes.json`（`ksmauto transcribe` の出力。`[[開始秒, 終了秒, MIDI, 強さ 0-1], ...]`）があればそれを使い、なければ `other` と同じ方法で音から取る。採譜を使うときは、35 ms 以内に始まる音を和音として 1 つの発音にまとめ、強さは最大、音程は最高音にする。最高音が、すでに鳴っている音のちょうど 1 オクターブ上なら倍音の誤検出として 1 オクターブ下げる。強さは曲中の 90 パーセンタイルで割る。

## テキスト（LLM 用）

```
BPM 191 (conf 0.92)  offset 132ms  4/4  duration 134.2s  measures 0-107
sections: A m0-7 (0.30) | B m8-15 (0.70) | A m16-23 (0.32) ...

m   energy  low              mid              high
0   0.12    x...x...x...x... ....x.......x... x.x.x.x.x.x.x.x.
1   0.15    x...x...x..xx... ....x.......x... x.x.x.x.x.x.x.x.
```

- 16分グリッドで、強さ 0.6 以上を `X`、0.3 以上を `x`、未満と無音を `.` で表す。3連が多い小節は 12 分割（`|` 区切り）で出す。
- `--stems` のときは列が `kick snare hat bass vocal other vpitch` になる。`bass` `vocal` `other` は発音以外で鳴り続けているマスを `=` で埋める。`vpitch` はボーカルの音程を曲の音域（5〜95 パーセンタイル、ヘッダに表示）の中で 0〜9 にしたもので、無声は `.`。`olane` は `other` の発音（`x` 以上）を `other_pitch` の高さで A〜D に割り当てたもの。前後 1 小節を含む 3 小節の 10〜90 パーセンタイルを 4 段に分ける（高い = 右）。音が上がれば右へ進むので、そのまま BT の階段の下書きになる。`piano.wav` があるときは `piano` の段と、同じ規則で `piano_pitch` から作る `plane` の列が増える。

```
stems: '=' = still sounding; vpitch 0-9 = vocal pitch over D4-C5 (low = left); olane = other-stem note as lane A-D by pitch within m-1..m+1

m   energy  kick             snare            hat              bass             vocal            other            vpitch           olane
10  0.86    ......X...X...X. x.....X...X.x.X. ...x..X...X...X. x=x==.===.x==.X= ==============x= x===x======xx=== 4556666676667676 D...A......BC...
```

## 精度評価

公式既定曲（`corpus/official/`）の譜面の `t=` / `o=` を正解として、`tests/eval/` で BPM と offset の誤差を測る。
既定曲はすべて `o=0`（音源の先頭が小節頭）で、BPM 変化はない。
offset は「拍の位相」（1拍の長さで割った余り）と「小節頭の位相」（1小節の長さで割った余り）に分けて評価する。
目標は BPM 誤差 ±0.5 以内（倍・半分は誤りとする）、拍の位相の誤差 ±15 ms 以内、それぞれ 8/10 曲以上。小節頭の位相は参考値として記録する。
