# 作譜ガイド（K-Shoot MANIA）

公式既定曲 36 譜面（`corpus/official/`）と sdvx.in の Lv17〜20 譜面（手元で復元、再配布しない）の統計と、SDVX 系譜面の一般的な作法をまとめたもの。数値は目安であり、曲に合わせて崩してよい。

## 操作系の前提

- BT は A B C D の 4 レーン、FX は L R の 2 レーン（BT の下、中央寄り）、レーザーは左（青, `l`）と右（赤, `r`）のつまみ。
- 手は 2 本。1 本の手が届くのは隣り合う 2 レーンまで（FX-L は B、FX-R は C の位置として数える）。
- **動いているレーザーは手を 1 本占有する**。止まっているレーザーは手を離してよい。
- 直角（slam）は鋭いアクセント。つまみを弾くので、直前直後に同じ側のボタンを置くと忙しい。

### 高難度帯 Lv17〜20（sdvx.in から復元した 1607 譜面の四分位範囲）

チェイン数と最高 BPM がページの表記と一致した譜面だけを数えている。

| レベル | 譜面数 | avg NPS | peak NPS | laser_ratio | FX/分 | 直角/分 | 同時押し率 | 16分連続の最長(秒) |
|---|---|---|---|---|---|---|---|---|
| 17 | 732 | 6.1-7.5 | 13-16 | 0.47-0.72 | 79-108 | 45-79 | 0.17-0.30 | 1.0-2.7 |
| 18 | 672 | 7.3-8.9 | 16-19 | 0.52-0.80 | 100-134 | 55-92 | 0.21-0.32 | 1.2-3.6 |
| 19 | 172 | 8.9-10.5 | 19-23 | 0.55-0.80 | 121-156 | 60-105 | 0.21-0.33 | 1.8-4.3 |
| 20 | 31 | 10-11.5 | 23-28 | 0.64-0.93 | 139-173 | 74-116 | 0.22-0.32 | 1.5-4.1 |

- この帯では「ボタンの物量」だけでなく、**レーザーを回しながらボタンを押す割合**（`knob_button_ratio`、どのレベルでも 0.2〜0.3）と直角の多さが難しさを作る。
- 16 分の連続は数秒程度まで。長い 16 分の乱打より、短い 16 分の塊を何度も置く方が多い。

- NPS はボタン（チップ）＋直角の数 / 秒。ロングは開始のみ数える。
- laser_ratio は「レーザーが出ている時間 / 曲の長さ」（左右の合計なので 1 を超えうる）。
- `ksmauto stats` の `level_estimate` は両コーパスから回帰したもの（平均誤差: どちらも 0.7 前後。20 で頭打ち）。目標レベルに対して ±1.5 以内に収める。Lv18 以上は推定値が 20 に張り付きやすいので、上の表の数値と直接比べる。

## 音と配置の対応

`analyze --stems` の段ごとの置き方（分離していなければ `low`/`mid`/`high` から推し量る）:

| 段 | 置き方 |
|---|---|
| `kick` | BT の表拍。強い `X` は A+D・B+C の同時押しで重さを出す。4 つ打ちを全部拾うと単調なので、メロディ側と交互に使う |
| `snare` | アクセント: FX チップ、直角、BT 同時押し。サビ頭・フィルの連打はここ |
| `hat` | 高難度の 16 分の刻み（階段・トリル）。裏打ちの 8 分は片手の交互や FX-L/R の交互に |
| `bass` | うねるベースはレーザーの揺れ、`=` で長く伸びるベースは FX ロング |
| `vocal` | 歌の区切り（`X` の位置）を BT で拾うか、レーザーで歌に沿う。`=` が長い伸ばしは BT/FX ロングやレーザーのゆっくりした移動 |
| `vpitch` | レーザーの位置の目安: 音程が上がる → 右へ、下がる → 左へ。サビのメロディをそのままレーザーでなぞると気持ちいい |
| `other` | シンセのリフ・アルペジオは BT の 16 分（階段・回転）、長いパッドは休憩区間のレーザー |
| `olane` | `other` の音の高さを A〜D にしたもの。ピアノ・シンセが主役の区間はこの並びを BT の下書きにする（下の「楽器別の型」） |
| 曲の山場（`sections` で energy が高い区間） | 密度を上げる。最も密度が高いのは最後のサビ付近にする |
| 静かな区間（energy 低） | 休憩。レーザーだけ、または 4 分のチップだけにする |

- 1 つの区間で主役を決める: 例えば A メロはボーカルをレーザー、ドラムを BT、サビはシンセのリフを BT、キックを FX、など。同じ区間に全部の楽器を詰めない。

- **すべてのボタンは何かの音に対応させる**。`ksmauto lint --analysis` の `unaligned` が 15% を超えたら見直す。
- 同じ区間が繰り返される（`sections` のラベルが同じ）なら同じ配置かミラーにする。`copy` を使う。ただし 2 回目のサビは少し密度を上げるなど変化をつけるとよい。
- 曲頭の 1〜2 小節と曲末は空ける（プレイヤーの準備・余韻）。

## FX の使い方

### FX チップ・FX ロング（Lv17〜20 実譜面の集計）

| 項目 | 17 | 18 | 19-20 |
|---|---|---|---|
| FX チップ / BT チップ | 0.21 | 0.26 | 0.27 |
| FX ロング / FX チップ | 0.56 | 0.41 | 0.30 |
| FX チップのうち L+R 同時 | 17% | 18% | 18% |
| FX チップのうち BT と同時 | 22% | 25% | 27% |
| FX チップのうち直角と同時 | 13% | 14% | 13% |
| FX チップのうち 4 分の位置 | 61% | 59% | 55% |
| FX ロングのうち 1 拍以下 | 78% | 78% | 74% |
| FX ロングのうち下で BT を叩くもの | 34% | 37% | 39% |

- **FX チップは単独で置く**のが基本。BT と重ねるのは 4 回に 1 回程度。BT の「ついで」に FX を足すと FX の存在感が消える。
- FX は 4 分の表拍が 6 割。スネア・クラップ・バックビートのような**拍の決まった重い音**を FX の役にする。続けて置くなら L/R の交互（同じ側の連打より 2 倍近く多い）。
- **L+R 同時**（両手で FX を叩く）はシンバル・クラッシュ・ブレイク明けの 1 打。FX の 2 割弱。
- 直角と同時の FX（つまみを弾きながら反対の手で FX）は 1 割強。スネアの直角と組にすると重い。
- **FX ロングは短いものが主**（1 拍以下が 4 分の 3）。伸ばした音・溜め・シンセの持続音を 1/2〜1 拍の FX ロングにし、その下で BT の刻みを叩かせる（ロングを押さえたままもう一方の手で BT）。長い FX ロング（4 拍超）はまれで、ビルドアップや曲末の溜めに限る。

### 音のエフェクト（公式 36 譜面の集計）

FX ロング・レーザーには KSM のエフェクトがかけられる（書き方は `references/draft-format.md` の「オーディオエフェクト」）。何も書かないと FX ロングはエフェクトなし、レーザーは `peaking_filter`。

| 場面 | エフェクト（公式での使用回数） | 書き方の例 |
|---|---|---|
| 刻み・連打を強調する FX ロング | `gate`（471）、`retrigger`（443）。1/16 か 1/8 が大半 | `0 L~1@gate(wave_length=1/16)` `0 R~2@retrigger(wave_length=1/8)` |
| うねり・持続音 | `flanger`（380）、`phaser`（51） | `0 L~2@flanger` |
| 歪んだ音・ノイズ | `bitcrusher`（211）。5〜10samples が多い | `0 R~1@bitcrusher(reduction=10samples)` |
| 曲の区切り・ブレイク前の停止 | `tapestop`（57）。speed 20〜50% | `def fx stop tapestop speed=30%` → `3 L~1@stop` |
| ワブルベース | `wobble`（36）、1/12 など | `0 L~2@wobble(wave_length=1/12)` |
| 4 つ打ちのうねり | `sidechain`（43） | `0 R~4@sidechain` |
| レーザー | 既定の `peaking_filter`、こもらせるなら `low_pass_filter`（83）、軽くするなら `high_pass_filter`（68） | `0 laser_effect low_pass_filter` |
| FX チップのキー音 | `clap` など（公式では少数）。スネアの FX に重ねる | `0 L@clap(vol=0.6)` |

- FX ロングのエフェクトは**その音が実際に鳴っている質感**に合わせる: 刻んだシンセ → `retrigger`/`gate`、うねるパッド → `flanger`、ブレイク前 → `tapestop`。曲と合わないエフェクトはかけない方がよい。
- `gate`/`retrigger` の刻みは曲の刻み（`hat` の 16 分か 8 分）と同じにする。
- 公式 36 譜面のうち 9 譜面は同じロングの途中でエフェクトを替えている（`fx_effect`）。ビルドアップで 1/8 → 1/16 と刻みを細かくしていく使い方ができる。
- レーザーのフィルタはセクションの雰囲気で切り替える（ブレイク・間奏で `low_pass_filter`、サビ頭で `peaking_filter` に戻す）。

## 楽器別の型

区間の主役の楽器を決めたら、その楽器を「弾いている」感覚になる型を使う。`olane` は形の下書きで、そのまま全部置く必要はない（縦連・偏りは型の方で直す）。

| 主役 | 型 | 書き方の例 |
|---|---|---|
| ピアノ（分散和音・アルペジオ） | **BT だけ**で音の高さどおりの階段。上がるフレーズは A→D、下がるのは D→A。和音の頭（左手の低音）は A か A+B の同時押し、続く分散音を右へ。FX・レーザーは休ませる | `0 A` `0.25 B` `0.5 C` `0.75 D` `1 C` `1.25 B` |
| ピアノ（コード打ち） | コードの打鍵を BT の 2〜3 個同時押し。高い和音は B+C+D、低い和音は A+B+C のように高さで寄せる | `0 A B C` `0.75 B C D` |
| シンセのアルペジオ・リード | 16 分の階段・回転（A B C D C B）。同じ音型の繰り返しは同じ形、音型が変わったら形も変える | `olane` が `ABCDABCD` なら階段、`ADAD` なら交互 |
| ギターのリフ・刻み | 低音弦の刻みは 1〜2 レーンの交互（A↔B など）、リフの決めはスライドする同時押し（A+B → B+C → C+D）。歪んだロングは FX ロング | `0 A B` `0.5 B C` `1 C D` |
| ストリングス・パッド | 長いレーザーのゆっくりした移動、または BT/FX ロング。上に乗るチップは少なく | `0 l 0 +4:0.5` |
| ボーカル | `vpitch` に沿ったレーザー。歌い出しを BT で拾い、伸ばしは BT ロング | `0 r 1 +2:0.6 +2:0.8` |
| ベース（うねる・スラップ） | レーザーの小さな揺れ、FX-L/R の交互 | `0 L` `0.5 R` |
| ドラムのフィル | タムの回りは BT の階段（高いタム = 右から左へ下りる）、締めのシンバルは直角か全押し | `3 D` `3.25 C` `3.5 B` `3.75 A` |

- 型を変えるのは主役が替わったとき。同じ区間の中で型を混ぜすぎない（「ピアノの 4 小節は BT だけ」のように、型ごとに使う操作を絞ると楽器の感じが出る）。
- ピアノの型は手の動きが鍵盤の左右と一致するのが肝。`olane` の高低がオクターブで飛んだ所（`other_pitch` が 12 違う）は、前後とつながる方のレーンへ寄せる。

## 配置の作法

- 縦連（同じレーンの連打）は 16 分以上の速さで続けない（`fast-jack`）。
- 階段（A→B→C→D）、トリル（A↔B）、交互（A↔D）を組み合わせ、同じ形を 2 小節以上ベタ打ちしない。
- レーザーが動いている間の空き手の置き方は下の「配置パターン」を見る（`hand-overload` は避ける）。
- 直角は 1 拍に 2 回程度まで（高難度を除く）。左右交互の直角はサビ頭の見せ場に使う。
- レーザーの値: 0 = 左端、1 = 右端。左レーザーは左端から、右レーザーは右端から始めるのが基本。
- 低難度ではレーザーをゆっくり大きく動かし、ボタンと同時に複雑な操作をさせない。

## 配置パターン（Lv17〜20 実譜面の集計）

`tests/eval/sdvxin_patterns.py` の集計（右レーザーは左右を反転して左に揃えている）。自作譜面も `--chart work/chart.kson` で同じ表を出して比べられる。

### レーザーを回している間の空き手

左つまみを回している間（傾きのある区間と、直角の前後 1/8 拍）のチップがどのレーンに来るか（ロングは数えない）:

| レベル | C | D | FX-R | B | FX-L | A |
|---|---|---|---|---|---|---|
| 17 | 34% | 28% | 16% | 16% | 4% | 3% |
| 18 | 31% | 25% | 17% | 17% | 5% | 4% |
| 19-20 | 30% | 23% | 18% | 18% | 7% | 4% |

- 反対側の 2 レーン（C/D）は 5〜6 割にとどまる。**FX-R とつまみ側の内側 B がそれぞれ 16〜18%** ある。B は空き手が中央へ伸ばして押す位置で、FX-L も少し使われる。A だけはほぼ使わない。
- 同時押しは C+D が 7%、B+C が 5〜6%、FX-L+FX-R が 1.5%。
- **1 回のつまみ操作の間、空き手は 1 つのボタンだけを叩くことが多い**（7 割前後）。2 レーン使うなら C+D か B+C。長いスイープの下で C/D/FX-R を全部散らす配置は実譜面ではまれ。
- 両方のつまみが動いている瞬間のチップは 1000 チップあたり 11〜18 個とわずか。

### つまみが止まっているとき

- 単押しが 8 割（B/C が各 20%、A/D が各 12〜14%、FX-L/FX-R が各 6〜7%）。同時押しでは B+C、C+D、A+B、FX-L+FX-R、A+D の順に多い。FX と BT の斜めの組（D+FX-L、C+FX-L）も 1% 前後ある。
- 16 分 4 連（間隔がちょうど 16 分のもの）の形: 階段 ABCD / DCBA が合わせて 17〜19%。次いで BC トリル（BCBC / CBCB）が 6〜9%、折り返し（BCDC、CDCB、CBAB、BABC）が各 3% 前後、回転（BCDA、DABC、CBAD、ADCB）と割れ（CDAB、BADC）が各 2〜3%。**1 つの形に偏らせない**（トリルばかりで 8 割を超えるような配置は不自然）。

### lint との関係

実譜面にも `hand-overload` は 1000 チップあたり 17〜27 個（Lv が上がるほど多い）、`fast-jack` は 4〜16 個ある。自作譜面では原則ゼロを目指すが、意図した見せ場なら数個は許容してよい。

## LIGHT → INFINITE の作り分け

1. まず最も音を拾った EXHAUST 相当を作る。
2. 下位難度はそこから間引く: 16 分 → 8 分 → 4 分、同時押しを単押しに、直角を減らす。
3. INFINITE はレーザーの複雑さ（細かい振り・直角の連続）か、ボタンの物量のどちらかに特化させると個性が出る。
